# Z150
```
Проект на базе Arduino Nano(atm328) для измерения скорости старйкбольного шара
по средству измерния времени пролёта его между 2-я точками на фиксированном 
растоянии (DISTANCE).

``` 

## НАСТРОЙКИ
```
DISTANCE   = 0.1  расстояние                            (м)      DIST
MIN_V      =  80  минимальная скорость выстрела         (м/с)    MN_V
MAX_V      = 150  максимальная скорость выстрела        (м/с)    MX_V
EXPECTED_V = 120  ожидаемая скорость                    (м/с)    ED_V
MASS       = 0.3  вес шара                              (г)      MASS
MAX_E      = 3.0  максимальная энергия выстрела         (джоуль) MX_E
SHOT_N     = 100  количество выстрелов для замеров      (штук)   ST_N
```
